# Mood-Based Study Planner 

A full-stack web application designed to help students plan their studies based on their mood and manage their study tasks more effectively.

## About the Project

The Mood-Based Study Planner aims to make study planning more personalized by allowing students to select their mood and receive study recommendations accordingly. It also helps users manage their study tasks in one place.

This project was built using **React, Node.js, Express.js, and MongoDB**.

##  Features

- **Mood-Based Study Planning:** Select your mood to receive relevant study recommendations.
- **Task Management:** Organize and manage study-related tasks.
- **Full-Stack Architecture:** Combines a React frontend with a Node.js and Express.js backend.
- **Database Integration:** Uses MongoDB for data storage.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/AnsikaSahoo/mood-based-study-planner.git
cd mood-based-study-planner
```

**2. Install dependencies**

Navigate to the frontend and backend directories and install their dependencies.

```bash

```

Run this command in each directory that has its own `package.json`.

Create a `.env` file in the appropriate backend directory and configure the required variables.
